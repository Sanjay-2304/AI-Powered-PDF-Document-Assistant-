Chatbot-with-RAG :
• Built an end-to-end Retrieval-Augmented Generation (RAG) pipeline for PDF question answering, integrating OpenAI GPT-OSS 120B via the Groq API with LangChain’s RetrievalQA chain. • Implemented PDF ingestion, recursive text chunking (1,000 characters, 100 overlap), and HuggingFace all-MiniLM-L12-v2 embeddings, stored in ChromaDB for top-3 semantic retrieval of relevant context. • Developed an interactive Streamlit chat interface with multi-turn conversation history, cached vector store loading, and source-document return for grounded, traceable responses.
